# Image library

One folder per entry, named after its file in `content/entries/`. Drop originals here at any size.

Nothing in this folder is published. When an image goes on the site, a web-sized copy is made into `public/entries/<slug>/` and listed under `images:` in the entry's frontmatter.

The originals are kept out of git; only the folders are tracked. A new entry needs its folder made by hand.
